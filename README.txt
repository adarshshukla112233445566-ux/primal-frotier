PRIMAL FRONTIER
===============

A browser-based 3D prehistoric survival action game.

PLAY LOCALLY
------------
1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

   python3 -m http.server 8080

4. Open http://127.0.0.1:8080/ in your browser.

Do not open index.html directly with file:// because browser module and asset loading policies can block the game.

CONTROLS
--------
WASD      Move
Mouse     Look around
Left click / J       Light attack
Hold right click / K Heavy attack
Space     Dodge roll
Shift     Sprint
E         Gather, carve, or interact
Q         Lock on
R         Use poultice
Tab       Satchel and crafting
M         Map
H         Controls
Esc       Pause
